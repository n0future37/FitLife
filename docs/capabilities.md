# 能力成熟度与验收边界

所有当前结果以STATE和本次报告为准；“有代码”“固定响应通过”“真实模型通过”“开放语义正确”分别记录。

| 能力 | 当前实现范围 | 验收方式与限制 |
|---|---|---|
| 主Agent和三领域子Agent | 任务覆盖、DAG、证据、综合、共享预算、整份确认 | 固定响应真实MCP/MySQL回归；实模另做少量验收，不预设质量提升 |
| 画像与记忆 | 唯一结构化画像，来源/版本/更正/忘记，临时约束日期与过期隔离，最近会话 | 不提供无限历史记忆，自由文本长期约束需明确保存 |
| 计划与活动 | 原周计划、进度、活动确认录入/删除及版本历史 | 计划分钟只统计支持活动，不以步数/力量组次换算 |
| 身体与训练 | 身体测量、步数、文字训练、反馈、确认删除 | 一般记录辅助，无诊断、伤病或动作医学评估 |
| 饮食 | 食物库、每100g/ml核算、餐食快照、照片估算、偏好 | 照片估算与核算分开，未知营养不补零 |
| 区间统计 | 身体首末/每日、训练步数、饮食不同来源 | 服务端计算；单次最多366天，超记录上限明确incomplete |
| 知识检索 | 有出处/摘要的已核对资料，关键词基线 | 未导入时not_configured；不迁入未经核对的旧资料，不冒充已建知识库 |
| 图片 | 标签/餐食结构化观察、人工核对、绑定版本确认 | 合成图验收不代表真实餐食/模糊标签准确率 |
| 视频 | 私有上传、后台采样、取消重试、证据时间、核对 | 最多3分钟，不包含旧精析/跨视频组拼接或完整计数实验 |
| 指定热量菜单 | 旧版实验已识别，生产入口未迁入 | 保留为后续实验，不能把旧失败方案标成已稳定交付 |
| 本地或第二平台模型 | 配置与Chat/Responses适配接口 | 未选定/部署本地模型，未核实第二供应商账户兼容 |
| 部署 | Windows、Linux镜像、现有MySQL/Redis、CI配置 | 本机验证与云CI分开；不对外发布，不作生产容量承诺 |

新增功能坚持“初态→用户请求→工具/候选→确认→数据库结果”的小闭环。
旧0.4归档保留，旧Fit历史指标不计入新版成果；实际个人贡献需本人确认后再用于简历。
