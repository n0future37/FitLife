最新完整度核查见[readiness-v1](readiness-v1.md)，完整实模基线见[experiments-v2-full](experiments-v2-full.md)；“有代码”“固定响应通过”“真实模型通过”“开放语义正确”分别记录。

| 能力 | 当前实现范围 | 验收方式与限制 |
|---|---|---|
| 主Agent和三领域子Agent | 任务覆盖、DAG、证据、综合、共享预算、整份确认 | 固定响应真实MCP/MySQL回归；完整实模84条68通过，修复定向复验单列，不预设质量提升 |
| 画像与记忆 | 唯一结构化画像，来源/版本/更正/忘记，临时约束日期与过期隔离，最近会话 | 不提供无限历史记忆，自由文本长期约束需明确保存 |
| 计划与活动 | 原周计划、进度、活动确认录入/删除及版本历史 | 计划分钟只统计支持活动，不以步数/力量组次换算 |
| 身体与训练 | 身体测量、步数、文字训练、反馈、确认删除 | 一般记录辅助，无诊断、伤病或动作医学评估 |
| 饮食 | 食物库、每100g/ml核算、餐食快照、照片估算、偏好 | 照片估算与核算分开，未知营养不补零 |
| 区间统计 | 身体首末/每日、训练步数、饮食不同来源 | 服务端计算；单次最多366天，超记录上限明确incomplete |

| 图片 | 标签/真实餐食粗估、人工核对、绑定版本确认 | 8张保留照片×3：23/24给估计，条件MAE173.51kcal，误差较大；见media-v2，不代表模糊标签准确率 |
| 视频 | V3.1完整时间轴相对往返计数、主训练者跟踪/镜头隔离、核对更正确认 | 指定动作非分类；80次对照旧集差1内4→12/20，新增均6/20，仍有少计/多计与弃权；详见video-v3，弯举未做真实准确率评测 |
| 指定热量菜单 | 旧版实验已识别，生产入口未迁入 | 保留为后续实验，不能把旧失败方案标成已稳定交付 |
