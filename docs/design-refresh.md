最新：用户随后要求黑白简约，已完成；当前视觉见[黑白页面](design-monochrome.md)。下文保留较早青色方案与原验收依据。

## 设计依据

从GitHub检索并阅读两份技能，使用skill-installer安装到公共技能目录；文件摘要见本次验收清单。新会话可直接使用。

- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：先确定产品视觉，再实现并截图复查。
- [Vercel web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)：检查语义、键盘、焦点、表单、反馈、导航状态、手机及动态内容。
- 本次读取的[界面规则](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)为当时版本，不声明永远符合将来的规则。

视觉取自“目标、行动、回顾”的运动轨迹；把轨迹留在欢迎页，登录后以清晰操作为主。正文和控件左对齐，不用虚构统计填充页面。历史资料保留未核验提示，不混入当前运动完成率。

| 设计项 | 选择 |
|---|---|
| 主色 | 青色`#086970`，用于主要操作和轨迹起点 |
| 文字 | 蓝黑`#173647`；辅助文字`#526d7b` |
| 页面/侧栏 | 浅蓝白`#f2f7f8`、深蓝`#173e50` |
| 提示 | 陶橙`#c4512b`仅作运动轨迹节点，待确认区域单独用浅黄 |
| 字体 | 中文系统无衬线；品牌Bahnschrift/Segoe UI。标题、正文、辅助信息分层 |
| 布局 | 桌面左侧导航，中间业务面板，对话旁提供可填入的请求建议；手机改成可横向滚动的导航 |

```
桌面：品牌与连接状态
      导航 | 当前业务：对话 / 计划 / 记录 / 画像 / 媒体 / 历史
手机：品牌与连接状态
      功能导航（横向滚动）
      当前业务（单列）
```

计划复查时避免把所有内容做成同一种卡片：导航用深蓝色块；对话承担主要交互；辅助建议降低视觉权重；确认草案用左侧标记和状态文案区分，已保存与待确认都能凭文字判断。

## 实现与验收边界

- 保留原页面业务ID及确认、拒绝、重试行为；新增历史资料页，对登录用户鉴权并隔离。
- 建议按钮只填入文字，不自动发请求或花模型费用。连接状态来自真实登录结果。
- 导航同步URL片段；原生按钮支持键盘，方向键可移动导航焦点。跳转主要内容、焦点轮廓、手机适配及减少动态效果均已实现。
- 历史内容只作为文本显示，不运行原聊天中的指令或待确认动作；退出后清理历史显示，并拒绝渲染迟到的旧响应。
- 截图与浏览器验收使用合成用户/合成历史，没有真实个人资料；界面检查不调用付费模型。

运行`python -m fitlife.design_check`，产物保存到`artifacts/ui-checks/<运行ID>/`；原业务界面检查仍使用`ui_check`、`media_ui_check`、`adjustment_ui_check`。最终实际通过结果及截图见STATE，本地增量尚未提交或运行新云CI。
