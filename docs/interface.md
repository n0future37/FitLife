# 本机界面

服务启动后访问`http://127.0.0.1:8100/`，输入本机manage命令生成的个人访问令牌。
不是模型密钥或数据库密码。令牌仅存在页面内存，刷新需重新连接；退出会撤销该令牌。
界面与API同源，无需Streamlit或前端构建环境。

四个页面提供多轮对话、候选确认/拒绝/时长修改、周计划/进度、活动录入/查询、
已确认偏好/来源查看、更正及忘记字段。删除对话保留运动事实。
模型执行失败时“重试刚才的请求”沿用请求键，用服务端缓存或候选恢复防重复。
每次只处理一个候选，未确认不宣称保存。

所有个人和模型文本使用textContent，不将其作为HTML；页面限制外部脚本，
接口响应禁用缓存。此版本为本机基础认证，外网部署前需HTTPS及正式身份接入，
不声称已完成公网企业身份或生产运维。

界面验收命令：fit解释器`-m fitlife.ui_check`。需要本机Chrome（FITLIFE_TEST_CHROME可指定），
采用独立临时无头资料目录，不控制日常浏览器、不读取原浏览器数据。
使用合成用户、固定模型回复、真实API/MySQL/MCP，无模型费用。
令牌只留验收进程和浏览器内存。测试结束撤销/清理合成数据并退出临时浏览器。
