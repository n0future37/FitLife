# FitLife 新版 Agent 探索实验最终报告

实验版本：experiments-v1；实验及补跑日期：2026-11-03。最终口径为原84次加补跑6次，共90次实际任务运行、258次已登记模型网络尝试；按预定位置合并为84条完整对照。旧项目E0–E6仅提供选题参考，旧指标不计入本报告。

## 1. 结论

本轮观察到独立查询的并发收益，以及同一密钥切换小模型处理简单查询的可行性。两者没有解决当前跨域路由、规划结构和工具义务衔接的失败。最近完整历史在本批任务中优于无历史及相关历史筛选，因此保持当前默认最近完整历史策略。优先修复任务正确性，再研究上下文压缩。

这些结论限于12个合成场景、每方案每场景3次重复，不代表真实用户总体成功率、生产SLA或独立会话分布泛化能力。

## 4. 效率与Token

延迟包含Agent请求、确认/拒绝及版本/越权/重放控制，排除夹具建立、清理及任务间等待。失败可能很快，因此只在同用例同重复且双方完整合同均通过的配对上讨论效率；完整失败率仍见上一节。标准差为总体标准差，不是置信区间。

- **N1**：3对成功并列查询，串行均值64.509秒（标准差22.683，范围46.252–96.479），DAG均值33.942秒（标准差9.629，范围20.985–44.048），本批均值减少47.38%。DAG子Agent实际重叠11.434–19.368秒，串行重叠0；两组任务结果仍各3/12，不能推断整体能力提升。

- **N2**：真正切8B的简单查询3对均成功，14.161±2.203→7.724±0.417秒；3次查询已知费用估算0.018656→0.002879元。主Agent仍使用32B；8B子模型在该公开价快照中单价为0。包含补问的6对双方成功任务均值12.038→9.559秒，费用估算0.063049→0.047273元；不是所有任务都切小模型，复杂调整仍失败。

## 5. 关键失败与修复优先级

1. **路由工具归属错误**：依赖查询将body工具列为exercise硬依赖，校验拒绝；一条同类串行运行整轮超时。跨领域事实传递需要明确语义和可执行归属。

2. **规划结构错误**：联合记录和画像合并将main列入agents/tasks/depends_on，违反main仅最终综合的约定，两次修复仍失败。可优先实验服务端构造合法节点/归属，以及带具体错误的结构修复反馈。

3. **工具义务不一致**：计划调整要求lookup_workouts_tool，子Agent实际读取get_plan_adjustment_context并生成正确草案，因硬依赖缺失未发布。训练明细与计划活动不是同一数据源，应对齐路由语义和执行义务，不能盲目放宽等价映射。

4. **筛选的间接影响**：日期指代筛选组3次中2次失败，日期/14分钟保留且工具参数正确，但路由新增未满足的query_activities义务；不能将该失败直接解释为信息被删。

5. **评测缺口**：前置冻结合法等价路径规则，补齐失败路径步骤计数，并用新保留集验证；当前已见场景后续作为回归集。以上修复尚未在本轮实现或验证效果。
